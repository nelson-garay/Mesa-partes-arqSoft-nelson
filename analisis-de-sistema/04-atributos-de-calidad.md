# Atributos de calidad

Sistema de Mesa de Partes Digital — Instituto Manuel Antonio Hierro Pozo

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | Rendimiento | El registro de un trámite nuevo no debe tardar significativamente más que el proceso manual actual (~30 segundos), incluso con varios usuarios conectados simultáneamente. |
| AC02 | Disponibilidad | El sistema debe estar disponible para la recepción de trámites en línea las 24 horas, incluyendo fuera del horario administrativo (8:00-16:00). |
| AC03 | Trazabilidad | El sistema debe permitir reconstruir el historial completo de cualquier trámite (derivaciones, cambios de estado, firmas) en cualquier momento. |
| AC04 | Seguridad | Las credenciales de usuario y las claves de firma electrónica deben estar protegidas frente a accesos no autorizados. |
| AC05 | Usabilidad | El personal administrativo, con nivel básico de manejo de computadoras, debe poder registrar y derivar un trámite sin necesitar capacitación extensa. |
| AC06 | Escalabilidad/Concurrencia | El sistema debe soportar el acceso simultáneo del personal de las 4 a 6 áreas definidas, sin degradación perceptible del desempeño. |
| AC07 | Mantenibilidad | El sistema debe estar organizado de forma que permita agregar nuevas áreas o tipos de documento sin afectar funcionalidades existentes. |
