# Historias de usuario

Sistema de Mesa de Partes Digital — Instituto Manuel Antonio Hierro Pozo

| ID | Historia de usuario |
|---|---|
| HU01 | Como usuario externo, quiero presentar un trámite en línea, para no tener que trasladarme presencialmente al instituto. |
| HU02 | Como usuario externo, quiero consultar el estado y ubicación de mi trámite, para saber en qué área se encuentra sin preguntar presencialmente. |
| HU03 | Como usuario externo, quiero recibir el documento de respuesta firmado electrónicamente, para contar con un documento válido sin firma física. |
| HU04 | Como usuario externo, quiero consultar al asistente IA mis dudas sobre cómo presentar un trámite, para resolverlas sin depender del personal de mesa de partes. |
| HU05 | Como personal de mesa de partes, quiero registrar un trámite físico recibido presencialmente, para mantener un respaldo en casos de alta responsabilidad.|
| HU06 | Como personal de mesa de partes, quiero derivar un trámite a la(s) área(s) correspondiente(s), para que sea atendido por el responsable adecuado. |
| HU07 | Como personal de mesa de partes, quiero consultar el historial completo de derivaciones de un trámite, para responder consultas de los usuarios sobre su estado. |
| HU08 | Como jefe de área, quiero visualizar los trámites que me han sido derivados, para gestionarlos oportunamente. |
| HU09 | Como jefe de área, quiero re-derivar un trámite a otra área o persona, para que sea atendido por quien corresponde cuando no es de mi competencia. |
| HU10 | Como jefe de área, quiero firmar electrónicamente los documentos de respuesta que genero, para formalizarlos sin requerir firma física. |
| HU11 | Como director, quiero firmar electrónicamente resoluciones y oficios, para formalizar documentos de alta jerarquía institucional. |
| HU12 | Como director, quiero consultar reportes generales de gestión documentaria, para supervisar el desempeño de todas las áreas. |
| HU13 | Como administrador del sistema, quiero gestionar los usuarios y sus roles, para controlar quién puede acceder y qué puede hacer en el sistema. |
| HU14 | Como administrador del sistema, quiero configurar las áreas y los tipos de documento, para mantener el sistema adaptado a la estructura institucional. |
| HU15 | Como verificador (cualquier persona), quiero verificar la autenticidad de un documento mediante un código o QR, para confirmar que no ha sido alterado y corresponde a quien lo firmó. |
